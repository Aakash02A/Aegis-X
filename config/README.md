# Aegis-X Configuration Templates

This directory houses non-sensitive, shared configuration templates and presets.

> [!CAUTION]
> Never place real API keys, production database passwords, private keys, or tokens in this folder.
> Real credentials should only be supplied via environment variables (`.env` locally, or your platform's secret manager in staging/production).

---

## 📁 Available Templates

* **`application.example.yml`**: Baseline environment property mappings for Spring Boot.
* **`../.env.example`**: Root environment variable template for local Docker / CLI startup.
